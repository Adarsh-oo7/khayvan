## ✦ Overview

KHAYVAN is a luxury haute-parfumerie digital teaser crafted in Next.js (App Router), React 19, and Tailwind CSS. The design embodies opulence, featuring an obsidian noir aesthetic, warm amber luminescence, fluid animations, olfactory notes showcase, and an interactive private VIP allocation waitlist.

## ✦ Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the page.

### 3. Build for production
```bash
npm run build
```
